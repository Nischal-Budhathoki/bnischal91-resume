# 🚀 Nischal Portfolio Platform

A modern, full-stack portfolio platform built with **Next.js**, **Node.js**, **TypeScript**, **Python**, and **DevOps** technologies. This project is more than a traditional portfolio—it's a production-ready platform that showcases my skills in frontend development, backend engineering, AI, automation, cloud infrastructure, and software architecture.

The goal is to build a scalable, maintainable, and enterprise-inspired application while continuously learning and implementing industry best practices.

* Build a modern portfolio platform using Next.js
* Develop scalable backend APIs
* Implement secure authentication and authorization

# 🚀 Getting Started

## Clone Repository

```bash
git clone <repository-url>
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on:

```
http://localhost:3000
```

---

## Backend

```bash
cd backend
npm install
npm run dev
```

---

## AI Services

```bash
cd ai-services

python -m venv venv

source venv/bin/activate

pip install -r requirements.txt

uvicorn api.main:app --reload
```

---

## Automation

```bash
cd automation
```

Configure workflows and environment variables before running automation services.
